# وایب نمونه — VibeNamune

وب‌سایت نمونه‌کار فارسی و راست‌چین، با پنل مدیریت، حالت روز و شب و تعامل سه‌بعدی
المان‌ها با نشانگر موس.

---

## اجرا

بار اول، وابستگی‌ها را نصب کنید:

```bash
npm run install:all
```

سپس نسخه‌ی نهایی را بسازید و سرور را بالا بیاورید:

```bash
npm run build
npm start
```

سایت روی <http://localhost:4173> بالا می‌آید. روی ویندوز می‌توانید به‌جای این دو
دستور، فایل `start.cmd` را اجرا کنید.

برای بردن سایت روی فلش، بخش «بردن سایت روی فلش» را در همین راهنما ببینید.

### حالت توسعه

```bash
npm run dev
```

سرور API روی پورت ۴۱۷۳ و نسخه‌ی توسعه‌ی فرانت‌اند روی <http://localhost:5173>
اجرا می‌شود و هر تغییری در کد بلافاصله دیده می‌شود.

## حساب کاربری و دسترسی مدیر

سایت یک در ورودی دارد: `/account`. همان‌جا هم «ورود» هست و هم «ثبت‌نام».

- **کاربر عادی** ثبت‌نام می‌کند تا بتواند زیر پروژه‌ها نظر بگذارد. همین و بس.
- **مدیر سایت** با حساب خودش وارد می‌شود و بلافاصله به پنل مدیریت می‌رود.

| نام کاربری | گذرواژه |
| --- | --- |
| `Mahdi` | `MNMZA450M24` |

هیچ لینکی به پنل مدیریت در سایت دیده نمی‌شود. تا وقتی با حساب مدیر وارد نشده
باشید، نشانی `/admin` دقیقاً همان صفحه‌ی «پیدا نشد» را نشان می‌دهد که هر نشانی
اشتباه دیگری نشان می‌دهد؛ یعنی وجود پنل اصلاً لو نمی‌رود. بعد از ورود، گزینه‌ی
«پنل مدیریت» زیر آیکن حساب در هدر ظاهر می‌شود.

**بعد از اولین ورود، گذرواژه را از بخش «تنظیمات» عوض کنید.**
برای ساخت حساب مدیر با مشخصات دلخواه، پیش از اولین اجرا:

```bash
VN_ADMIN_USER=myname VN_ADMIN_PASS=my-strong-pass npm start
```

اگر می‌خواهید همه چیز از نو ساخته شود، فایل `server/data/vibenamune.db` را پاک
کنید؛ محتوا و حساب مدیر دوباره از روی مقادیر بالا ساخته می‌شوند.

## بخش‌های پنل

| بخش | کار |
| --- | --- |
| داشبورد | شمار پروژه‌ها، نظرها، کاربران، رسانه‌ها، پیام‌های خوانده‌نشده و بازدیدها |
| پروژه‌ها | افزودن، ویرایش، انتشار یا پیش‌نویس کردن و حذف نمونه‌کارها |
| دسته‌بندی‌ها | بخش‌های اصلی سایت، نشان، رنگ، متن معرفی و نوشته‌ی دکمه‌ی هر دسته |
| نظرها و کاربران | خواندن و حذف نظرها، و فهرست حساب‌هایی که در سایت ساخته شده‌اند |
| پیام‌ها | صندوق پیام‌های فرم تماس، با علامت‌گذاری خوانده‌شده و پاسخ با ایمیل |
| تنظیمات | شش بخش جدا: هویت سایت، صفحه‌ی خانه، درباره، تماس، کاربران و نظرها، نمایش و فوتر |

### تصویر، ویدیو و لوگو برای هر نمونه‌کار

در فرم هر پروژه دو جعبه‌ی جداگانه هست:

- **تصویرها و ویدیوها** — فایل را مستقیم بارگذاری کنید یا نشانی `https` بچسبانید.
  هر مورد توضیح دلخواه و ترتیب قابل جابه‌جایی دارد. تصویر تا ۸ مگابایت و ویدیو تا
  ۸۰ مگابایت. روی صفحه‌ی پروژه به شکل یک گالری با قابلیت بزرگ‌نمایی دیده می‌شوند.
- **لوگوی اختصاصی** — اگر بگذارید، به‌جای نشان آماده روی کارت، صفحه‌ی پروژه و
  نتیجه‌ی جست‌وجو نمایش داده می‌شود. خالی بگذارید تا نشان آماده برگردد.

فرمت‌های پذیرفته‌شده: PNG، JPG، WebP، GIF، MP4 و WebM. فایل‌ها در
`server/data/uploads/` ذخیره می‌شوند. SVG عمداً پذیرفته نمی‌شود چون می‌تواند
اسکریپت داشته باشد.

### نظرها

زیر هر پروژه بخش نظر هست. خواندن برای همه آزاد است، اما نوشتن فقط برای کسی که
حساب ساخته و وارد شده. هر کاربر می‌تواند نظر خودش را پاک کند و مدیر می‌تواند هر
نظری را پاک کند. کل بخش نظرها و همچنین ثبت‌نام را می‌توانید از «تنظیمات ← کاربران
و نظرها» خاموش کنید.

### نوشته‌ی دکمه‌ی هر دسته

هر دسته‌بندی نوشته‌ی دکمه‌ی خودش را دارد، چون «سفارش پروژه‌ی مشابه» برای یک
پلاگین بی‌معنی است. پیش‌فرض‌ها: پلاگین‌ها «خرید این پلاگین»، ربات‌های تلگرام
«سفارش ربات مشابه»، نرم‌افزارها «سفارش نرم‌افزار مشابه»، طراحی وب «سفارش پروژه‌ی
مشابه». هرکدام را از فرم همان دسته عوض کنید.

در فرم پروژه، متن کامل از یک نشانه‌گذاری بسیار ساده پیروی می‌کند: خطی که با `##`
شروع شود تیتر می‌شود و خطی که با `-` شروع شود یک ردیف فهرست.

## بردن سایت روی فلش و اجرا روی کامپیوتر دیگر

یک دستور، یک پوشه‌ی آماده می‌سازد:

```bash
npm run package
```

پوشه‌ای به نام `VibeNamune-Portable` کنار همین پوشه ساخته می‌شود، حدود **۴ مگابایت**.
همان را روی فلش کپی کنید. روی کامپیوتر مقصد فقط `start.cmd` را دوبار کلیک کنید؛
مرورگر خودش باز می‌شود.

**تنها پیش‌نیاز کامپیوتر مقصد:** Node.js نسخه‌ی ۲۲.۵ یا بالاتر.
اگر نصب نباشد یا قدیمی باشد، `start.cmd` پیام فارسی روشن می‌دهد و کاری نمی‌کند.
اینترنت لازم نیست؛ نسخه‌ی ساخته‌شده و وابستگی‌های سرور همراه پوشه می‌روند.

چند نکته که جلوی دردسر را می‌گیرد:

- پوشه‌ی ۶۹ مگابایتی `client/node_modules` همراه نمی‌رود، چون فقط برای **ساختن**
  دوباره‌ی فرانت‌اند لازم است نه برای اجرا. اگر روی کامپیوتر مقصد کد را عوض کردید و
  خواستید دوباره بسازید، یک بار `npm run install:all` با اینترنت کافی است.
- پایگاه داده عمداً در حالت تک‌فایلی کار می‌کند. فایل `server/data/vibenamune.db`
  همیشه کامل است و فایل جانبی `-wal` یا `-shm` ساخته نمی‌شود، پس کپی کردن پوشه یا
  جدا کردن فلش، داده‌ای را ناقص نمی‌گذارد.
- برای بستن سایت در پنجره‌ی مشکی `Ctrl+C` بزنید. سرور امن بسته می‌شود و بعد
  می‌توانید فلش را جدا کنید.
- سرور فقط روی `127.0.0.1` گوش می‌دهد، پس ویندوز هشدار فایروال نمی‌دهد و سایت از
  بیرون آن کامپیوتر باز نمی‌شود. اگر خواستید از گوشی همان شبکه هم باز شود:
  `set VN_HOST=0.0.0.0` پیش از اجرا.
- تمام محتوای سایت در همان یک فایل `.db` است. برای پشتیبان‌گیری فقط از آن کپی بگیرید.

## ساختار پوشه‌ها

```
.
├── server/            بک‌اند: Express + SQLite داخلی نود
│   ├── src/
│   │   ├── index.js       ساخت اپ، هدرهای امنیتی، سرو کردن فایل‌های ساخته‌شده
│   │   ├── db.js          جدول‌ها، ایندکس‌ها و داده‌ی اولیه
│   │   ├── auth.js        رمزنگاری گذرواژه و جلسه‌ی کوکی
│   │   ├── seed-data.js   محتوای اولیه‌ی سایت
│   │   └── routes/        مسیرهای عمومی، ورود و پنل
│   └── data/          پایگاه داده و پوشه‌ی uploads (خودکار ساخته می‌شوند)
├── client/            فرانت‌اند: React + TypeScript + Vite
│   ├── public/fonts/  وزیرمتن، فقط با نویسه‌های لازم
│   └── src/
│       ├── components/  هدر، فوتر، کارت‌ها، صحنه‌ی سه‌بعدی، نشان‌ها
│       ├── lib/         ارتباط با API، حالت برنامه، موتور حرکت، قالب‌بندی
│       ├── pages/       صفحه‌های عمومی و صفحه‌های پنل
│       └── styles/      توکن‌های طراحی، سایت، پنل
└── scripts/dev.js     اجرای هم‌زمان API و فرانت‌اند
```

## نکته‌های فنی

- **پایگاه داده** روی ماژول داخلی `node:sqlite` اجرا می‌شود؛ هیچ وابستگی باینری
  لازم نیست و فایل داده در `server/data/vibenamune.db` ساخته می‌شود.
- **گذرواژه‌ها** با `scrypt` و نمک تصادفی ذخیره می‌شوند و مقایسه‌شان
  زمان‌ثابت است. جلسه‌ها در پایگاه داده نگه‌داری می‌شوند تا خروج از حساب
  واقعاً باطلشان کند.
- **حرکت المان‌ها** با نوشتن متغیرهای CSS روی خود عنصر انجام می‌شود، نه با
  رندر دوباره‌ی React؛ به همین دلیل حرکت موس هیچ هزینه‌ای روی رابط ندارد.
- **دسترس‌پذیری**: اگر کاربر در سیستم‌عاملش «کاهش حرکت» را روشن کرده باشد،
  تمام انیمیشن‌ها خاموش می‌شوند.
- **امنیت**: هدر `Content-Security-Policy` سخت‌گیرانه تنظیم شده و اسکریپت
  درون‌خطی با هش مجاز می‌شود؛ فرم تماس، ثبت‌نام، ورود و ثبت نظر همگی محدودیت
  تعداد درخواست دارند. مسیرهای پنل برای غیرمدیر پاسخ ۴۰۴ می‌دهند، نه ۴۰۳، تا
  وجودشان معلوم نشود.
- **بارگذاری فایل** بدون هیچ کتابخانه‌ی جانبی انجام می‌شود: خود فایل به‌عنوان بدنه‌ی
  درخواست فرستاده می‌شود و سرور آن را با شمارش بایت و سقف حجم روی دیسک می‌نویسد.
- **حجم بارگذاری**: کد سایت حدود ۲۱ کیلوبایت فشرده، کتابخانه‌ها حدود ۸۳
  کیلوبایت و استایل حدود ۱۲ کیلوبایت است. کد پنل مدیریت جداگانه بسته‌بندی شده و
  برای بازدیدکننده‌ی عادی اصلاً دانلود نمی‌شود.
- **سئو**: هر صفحه عنوان، توضیح، نشانی canonical و کارت اشتراک‌گذاری مخصوص خودش را
  دارد؛ `robots.txt` و `sitemap.xml` هم به‌صورت زنده از روی محتوای پایگاه داده
  ساخته می‌شوند. داده‌ی ساخت‌یافته‌ی schema.org روی همه‌ی صفحه‌ها هست.
- **نصب روی گوشی**: فایل `manifest.webmanifest` و آیکن‌ها موجودند، پس سایت را
  می‌توان مثل یک برنامه به صفحه‌ی خانه‌ی گوشی اضافه کرد.
- **دسترس‌پذیری**: لینک «پرش به محتوای اصلی» برای کاربران صفحه‌کلید، حالت فوکوس
  روشن روی همه‌ی عناصر تعاملی، و خاموش شدن کامل انیمیشن‌ها با «کاهش حرکت».
- **سلامت سرویس**: نشانی `/api/health` وضعیت سرور را برمی‌گرداند.

## متغیرهای محیطی

| متغیر | پیش‌فرض | کار |
| --- | --- | --- |
| `PORT` | `4173` | پورت سرور |
| `VN_DB_PATH` | `server/data/vibenamune.db` | مسیر فایل پایگاه داده |
| `VN_ADMIN_USER` | `Mahdi` | نام کاربری مدیر، فقط بار اول |
| `VN_ADMIN_PASS` | `MNMZA450M24` | گذرواژه‌ی مدیر، فقط بار اول |
| `VN_HOST` | `127.0.0.1` | برای دسترسی از شبکه‌ی محلی روی `0.0.0.0` بگذارید |
| `VN_SITE_URL` | — | نشانی عمومی سایت؛ در `sitemap.xml` و `robots.txt` استفاده می‌شود |
| `VN_HTTPS` | — | اگر `1` باشد و `NODE_ENV=production`، کوکی جلسه فقط روی HTTPS فرستاده می‌شود |
